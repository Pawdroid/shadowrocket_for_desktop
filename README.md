# Shadowrocket for Windows & macOS

小火箭桌面版官方发布仓库。内置免费节点,启动即可一键连接;会员兑换码与 Android 版通用,一个兑换码可同时在一台手机和一台电脑上使用,无需注册登录。

Official releases of Shadowrocket for desktop. Free servers are built in; one redeem code activates Premium on one phone and one computer at the same time, no account needed.

## 下载 / Download

最新版本见 [Releases](https://github.com/Pawdroid/shadowrocket_for_desktop/releases/latest)。

| 平台 / Platform | 文件 / File |
|---|---|
| Windows x64 | `Shadowrocket-windows-64.zip` |
| Windows ARM64 | `Shadowrocket-windows-arm64.zip` |
| macOS Apple Silicon | `Shadowrocket-macos-arm64.dmg` |
| macOS Intel | `Shadowrocket-macos-64.dmg` |

- Windows:解压后运行 `Shadowrocket.exe`。首次运行若出现 SmartScreen 提示,点「更多信息 → 仍要运行」。
- macOS:已签名并经 Apple 公证,打开 dmg 拖入「应用程序」即可。
- 国内下载镜像 / CDN mirror: `https://cdn.apkof.com/desktop/<version>/`(下载页 https://shadowrockets.app/download/#desktop)。
